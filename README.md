# Inwi-affichage-forfaits-

Prototype de réorganisation de l'affichage des forfaits inwi.

Nouveau concept : passer d'un carrousel de forfaits à une expérience de
comparaison et de recommandation (filtres, comparateur, questionnaire
« Aidez-moi à choisir »).

## Lancer le prototype

```bash
npm install
npm run dev
```

Stack : React + TypeScript + Vite + Tailwind CSS.
